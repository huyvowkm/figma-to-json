    How to use
    1. Run node "/path/to/figma-to-json/bin/bridge.mjs" "/path/to/project" "/path/to/project/.figma-cache" in a terminal. Keep it running.
    2. Run the plugin. It finds active local folders automatically. If yours is not listed, enter its localhost URL under Manual connection.
    3. Export. JSON goes into .figma-cache/exported; assets go into .figma-cache/assets.
    How to use
    1. Select the frames or components to export.
    2. Choose JSON only or JSON + assets in the main view, then click Prepare downloads.
    3. Click each link. Files download separately; to preserve asset paths, put JSON in exported and assets in sibling assets folders.
