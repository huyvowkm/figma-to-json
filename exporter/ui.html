    How to use
    1. Open a terminal in the folder you want to use, then run node "/path/to/figma-mcp/bin/figma-mcp.mjs". It uses that current folder. You can instead pass --output-dir "PATH_TO_FOLDER". Keep the command running.
    2. Return to the exporter and select the folder that appears, or enter a manual connection.
    3. Export. JSON files go into exported; image fills and explicitly named icons are saved in sibling assets. Keyboard-named subtrees are excluded from SVG exports. JSON nodes show name-match, excluded-keyboard, or not-detected.
    How to use
    1. Select the frames or components to export.
    2. Choose JSON only or JSON + assets in the main view, then click Prepare downloads.
    3. Click each link. Files download separately; to preserve asset paths, put JSON in exported and assets in sibling assets folders.
